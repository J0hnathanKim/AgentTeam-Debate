# 소방 보고서 4인 에이전트팀 (예제)

전문가 3명이 주제를 놓고 토론한 뒤, 문서작성자 에이전트가 그 결론을 정해진 양식의 `.docx`로 작성해주는 예제입니다. 디스코드 채널에 메시지 하나만 보내면 끝까지 자동으로 진행됩니다.

- **김장비** — 소방용품 전문가 (현장 실무 관점)
- **김유엘** — UL 소방인증용품 전문가 (해외 인증 비교 관점)
- **김공학** — 소방기술사 (화재공학·시스템 설계 관점)
- **김문서** — 공공기관 문서작성자 (위 세 명의 합의 결과를 양식에 맞춰 문서화)

이 폴더를 그대로 써도 되고, 자기 주제에 맞게 통째로 복사해서 페르소나만 바꿔도 됩니다 (맨 아래 [내 주제로 바꾸기](#내-주제로-바꾸기) 참고).

## 1. 준비물

- 이 저장소(루트)의 [설치 가이드](../../SETUP.md) ([Windows용](../../docs/SETUP-WINDOWS.kr.md))를 따라 디스코드 봇이 이미 떠 있는 상태
- 터미널에서 `claude` 실행 후 로그인 완료 (API 키 아님, Claude Pro/Max 구독 로그인)
- Node.js 20 이상

## 2. 이 예제 등록하기

1. 봇의 `.env`에서 `BASE_PROJECT_DIR`이 이 저장소를 클론한 경로를 포함하도록 설정되어 있는지 확인하세요.
   (예: `BASE_PROJECT_DIR=D:\Projects`로 두고 이 저장소를 `D:\Projects\AgentTeam-Debate`에 클론)
2. 디스코드에서 이 팀을 사용할 채널로 이동해서:
   ```
   /register AgentTeam-Debate/examples/fire-safety-report-team
   ```
3. `tools/` 폴더의 docx 생성 스크립트가 쓸 패키지를 한 번만 설치합니다:
   ```bash
   cd examples/fire-safety-report-team/tools
   npm install
   ```

## 3. 각 페르소나를 실제로 다른 이름으로 보이게 하기 (선택)

봇 초대 시 **Manage Webhooks**(웹훅 관리) 권한을 함께 체크했다면, 토론 중 김장비/김유엘/김공학이 각자 이름과 아이콘으로 메시지를 따로 남깁니다. 이 권한이 없어도 동작은 하지만, 모든 메시지가 봇 계정 이름으로만 나갑니다.

## 4. 사용해보기

등록한 채널에 그냥 평범한 메시지를 보내면 됩니다 (슬래시 명령어 아님):

> 국내 감지기 문제점과 개선방안 보고서 작성해줘

진행 순서:
1. 김장비·김유엘·김공학이 각자 1차 의견을 냄 (완료되는 대로 하나씩 채널에 표시)
2. 서로의 의견을 보고 동의/반박하는 2차 토론
3. 오케스트레이터(김문서 봇 본체)가 합의된 결론을 종합
4. 김문서가 그 내용을 양식에 맞춰 `.docx`로 작성 (`output/` 폴더에 생성)
5. 생성된 `.docx`가 자동으로 채널에 첨부됨

`Auto-approve`가 꺼져 있으면 문서 생성(Bash 실행) 시점에 승인 버튼이 뜹니다. 매번 누르기 번거로우면 채널에서 `/auto-approve on`을 실행하세요.

## 내 주제로 바꾸기

다른 도메인에 그대로 적용할 수 있습니다:

1. 이 폴더(`examples/fire-safety-report-team/`)를 새 이름으로 복사
2. `.claude/agents/*.md` 4개 파일의 `description`과 본문(페르소나 설명)을 원하는 전문가로 교체 — 파일명(`name:` 필드)은 자유롭게 바꿔도 되지만, `doc-writer.md`처럼 "마지막에 문서화만 담당하는" 역할 하나는 유지하는 걸 추천
3. `CLAUDE.md`의 팀 구성/워크플로 설명을 새 페르소나 이름으로 수정
4. 출력 양식을 바꾸고 싶으면 `tools/generate-report.mjs`와 `tools/report-schema.md`를 참고해 섹션 구조를 조정 (완전히 다른 문서 형식을 원하면 이 스크립트를 새로 작성해도 됨)
5. 새 채널에 `/register <새 폴더 경로>`로 등록

## 문제 해결

- **"Invalid path" 에러** — 루트 저장소 최신 버전인지 확인하세요 (`BASE_PROJECT_DIR`이 드라이브 루트일 때의 경로 검증 버그가 이 프로젝트에서 수정됨).
- **메시지 보내도 "Thinking..."에서 안 움직임** — Windows에서 발생했던 PATH 구분자 버그도 이 저장소에서 수정되어 있습니다. 그래도 안 되면 `claude` CLI가 로그인되어 있는지(`claude -p "hi"`로 확인) 먼저 점검하세요.
- **전문가별로 이름이 안 나뉘고 봇 이름으로만 옴** — 봇 초대 권한에 Manage Webhooks가 빠졌을 가능성이 큽니다. Discord 서버 설정 → 연동 → 해당 봇 권한에서 추가하거나, 봇을 Manage Webhooks 권한 포함해서 다시 초대하세요.
